# TAFRA — Wear Your Confidence

متجر TAFRA: صفحة واحدة، من غير أي build. كل البيانات في `catalog.js`.

## الملفات

| ملف | فيه إيه |
|---|---|
| `index.html` | هيكل الصفحة (هيرو، مجموعات، الأكثر طلبًا، متجر، لك بوك، دليل موضة، مقاسات، أسئلة، من نحن، تواصل) |
| `catalog.js` | **كل حاجة تتعدّل**: رقم الواتساب، الإيميل، الشحن، المجموعات، المنتجات، جدول المقاسات، الأسئلة |
| `2.js` | المنطق: عربي/إنجليزي، رسم المنتجات، بحث وفلترة وترتيب، أوردر واتساب، فورم الرسائل |
| `2.css` | التنسيقات |
| `img/` | صور البراند |
| `img/art/` | رسومات SVG بأسلوب البراند، بديل مؤقت لصور المنتجات |

> ⚠️ **الأسعار والمقاسات والأقمشة في `catalog.js` قيم مبدئية** كتبتها من غير ما أشوف المنتجات الحقيقية. راجعها وعدّلها قبل ما تفتح الطلبات فعليًا.

## تضيف منتج جديد

افتح `catalog.js` وانسخ سطر من مصفوفة `products` وغيّر القيم:

```js
{
  id: 'TF-005', cat: 'oversized', img: 'img/اسم-الصورة.jpeg',
  ar: { name: 'اسم عربي', desc: 'وصف عربي' },
  en: { name: 'English name', desc: 'English description' },
  colors: ['black'], sizes: ['M','L'], price: null, soon: false
}
```

- `price: null` → يبان «السعر عند الطلب». حط رقم (`450`) عشان يبان «450 ج.م».
- `sizes: []` → مفيش اختيار مقاس. اكتب مقاسات عشان تظهر أزرار في نافذة التفاصيل.
- `soon: true` → شارة «قريباً» على الكارت.
- `cat` لازم يكون واحد من الـ `id` الموجودة في `collections`.
- الصور تحطها في `img/` باسم إنجليزي من غير مسافات.

## الطلب

كل زرار «اطلب الآن» بيفتح واتساب على `brand.whatsapp` برسالة جاهز فيها اسم القطعة ورقمها والمقاس واللون اللي اختارهم العميل.

## فورم التواصل

بيكتب في نفس صندوق رسائل العملاء بتاع البورتفوليو عن طريق دالة Supabase العامة `portfolio_submit_lead`، والرسالة بتوصل `p_page: '/tafra'`. مفتاح الـ publishable علني بالتصميم — الصلاحيات كلها جوه الدوال في `portfolio/sql/portfolio-leads.sql`.
